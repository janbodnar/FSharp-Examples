# Random

Random number generation is fundamental for simulations, games, testing,  
and cryptographic applications. F# provides access to .NET's Random  
class along with functional programming patterns for elegant random  
data generation.  

Generating random values became more robust. Since 2016, in .NET Core  
the default seed has been changed from `Environment.TickCount` to  
`Guid.NewGuid().GetHashCode()`. It makes 'safe' to create several  
random instances in a loop without getting identical sequences.  

F# excels at random data generation through its immutable collections,  
sequence expressions, and functional composition. You can easily create  
random sequences, apply transformations, and combine multiple random  
sources using pipes and higher-order functions.

## Print random value

```F#

for _ in 1..20 do
    let r = rnd.Next(1, 100)

printfn ""
```
Print 20 random values between 1 and 99. Upper bound is exclusive.

## Random vals from endless seq

Infinite sequences provide lazy evaluation for generating unlimited  
random data without memory overhead.  

```F#

let rnd = Random()

let randomVals =
    seq {

            yield rnd.Next(100)
    }

    randomVals
    |> Seq.truncate 10
    |> Seq.sort
    |> Seq.toList

```

The sequence expression creates an infinite stream of random numbers.  
Values are generated on-demand when consumed, making this memory  
efficient for large datasets. The pipe operations filter and transform  
the sequence functionally.

## Weighted random selection

Weighted selection allows different probabilities for different outcomes  
based on assigned weights.  

```F#
open System

type Item = { Name: string; Weight: int }

let items = [
    { Name = "Common"; Weight = 70 }
    { Name = "Uncommon"; Weight = 20 }
    { Name = "Rare"; Weight = 8 }
    { Name = "Epic"; Weight = 2 }
]

let selectWeighted items =
    let totalWeight = items |> List.sumBy (fun i -> i.Weight)
    let rnd = Random().Next(1, totalWeight + 1)
    
    let rec find acc = function
        | [] -> failwith "No item found"
        | item :: rest ->
            let newAcc = acc + item.Weight
            if rnd <= newAcc then item.Name
            else find newAcc rest
    
    find 0 items

for _ in 1..10 do
    printfn "%s" (selectWeighted items)
```

This implements a weighted random selection algorithm. Items with higher  
weights have proportionally higher chances of being selected, useful  
for game loot systems or statistical sampling.

## Fisher-Yates shuffle algorithm

The Fisher-Yates shuffle provides unbiased random permutations of  
sequences.  

```F#
open System

let fisherYatesShuffle (arr: 'T[]) =
    let rnd = Random()
    let result = Array.copy arr
    
    for i in result.Length - 1 downto 1 do
        let j = rnd.Next(i + 1)
        let temp = result.[i]
        result.[i] <- result.[j]
        result.[j] <- temp
    
    result

let cards = [| 1..10 |]
let shuffled = fisherYatesShuffle cards

printfn "Original: %A" cards
printfn "Shuffled: %A" shuffled
```

This classic algorithm ensures each permutation has equal probability.  
The implementation works backwards through the array, swapping each  
element with a randomly selected element from the remaining positions.

## Random sampling without replacement

Sampling without replacement selects unique elements from a collection  
without duplicates.  

```F#
open System

let sampleWithoutReplacement count (source: 'T list) =
    let rnd = Random()
    let sourceArray = List.toArray source
    let shuffled = Array.sortBy (fun _ -> rnd.Next()) sourceArray
    shuffled |> Array.take (min count sourceArray.Length) |> Array.toList

let population = [ 1..20 ]
let sample = sampleWithoutReplacement 7 population

printfn "Population: %A" population
printfn "Sample: %A" sample
```

The algorithm shuffles the source collection and takes the first n  
elements. This ensures no duplicates and maintains uniform distribution  
across all possible samples of the given size.

## Monte Carlo pi estimation

Monte Carlo methods use random sampling to solve mathematical problems  
through statistical approximation.  

```F#
open System

let estimatePi trials =
    let rnd = Random()
    let mutable insideCircle = 0
    
    for _ in 1..trials do
        let x = rnd.NextDouble()
        let y = rnd.NextDouble()
        if x * x + y * y <= 1.0 then
            insideCircle <- insideCircle + 1
    
    4.0 * float insideCircle / float trials

let trials = 1000000
let piEstimate = estimatePi trials

printfn "Estimated π: %.6f" piEstimate
printfn "Actual π:    %.6f" Math.PI
printfn "Error:       %.6f" (abs (piEstimate - Math.PI))
```

This estimates π by randomly sampling points in a unit square and  
counting those inside the inscribed circle. The ratio approximates  
π/4, demonstrating Monte Carlo simulation principles.

## Random walk simulation

Random walks model stochastic processes in physics, finance, and  
biology.  

```F#
open System

type Position = { X: int; Y: int }

let randomWalk steps =
    let rnd = Random()
    let directions = [ (0, 1); (1, 0); (0, -1); (-1, 0) ]
    
    let rec walk pos path remaining =
        if remaining = 0 then pos :: path
        else
            let (dx, dy) = directions.[rnd.Next(4)]
            let newPos = { X = pos.X + dx; Y = pos.Y + dy }
            walk newPos (pos :: path) (remaining - 1)
    
    walk { X = 0; Y = 0 } [] steps |> List.rev

let path = randomWalk 20
path |> List.iteri (fun i pos -> printfn "%2d: (%2d, %2d)" i pos.X pos.Y)

let finalDistance = 
    let final = List.last path
    sqrt (float (final.X * final.X + final.Y * final.Y))
printfn "Final distance from origin: %.2f" finalDistance
```

The simulation tracks a particle's position as it moves randomly in  
four directions. This demonstrates path-dependent random processes  
and statistical analysis of random movement.

## Random password generation

Secure password generation requires character variety and sufficient  
entropy.  

```F#
open System

type CharSet = {
    Lower: string
    Upper: string
    Digits: string
    Symbols: string
}

let charSet = {
    Lower = "abcdefghijklmnopqrstuvwxyz"
    Upper = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    Digits = "0123456789"
    Symbols = "!@#$%^&*()_+-=[]{}|;:,.<>?"
}

let generateSecurePassword length =
    let rnd = Random()
    let allChars = charSet.Lower + charSet.Upper + charSet.Digits + charSet.Symbols
    
    // Ensure at least one character from each set
    let mandatory = [
        charSet.Lower.[rnd.Next(charSet.Lower.Length)]
        charSet.Upper.[rnd.Next(charSet.Upper.Length)]
        charSet.Digits.[rnd.Next(charSet.Digits.Length)]
        charSet.Symbols.[rnd.Next(charSet.Symbols.Length)]
    ]
    
    let remaining = length - mandatory.Length
    let randomChars = [ for _ in 1..remaining -> allChars.[rnd.Next(allChars.Length)] ]
    
    (mandatory @ randomChars)
    |> List.sortBy (fun _ -> rnd.Next())
    |> List.toArray
    |> String

for _ in 1..3 do
    printfn "%s" (generateSecurePassword 16)
```

This generates passwords with guaranteed character diversity. The  
algorithm ensures representation from each character class while  
maintaining randomness through final shuffling.

## Gaussian random distribution

Normal distribution random values are essential for statistical  
modeling and realistic simulations.  

```F#
open System

let generateGaussianRandom mean stdDev =
    let rnd = Random()
    
    // Box-Muller transformation
    let u1 = rnd.NextDouble()
    let u2 = rnd.NextDouble()
    
    let z0 = sqrt(-2.0 * log(u1)) * cos(2.0 * Math.PI * u2)
    mean + stdDev * z0

let gaussianValues = [ for _ in 1..100 -> generateGaussianRandom 50.0 15.0 ]

printfn "Mean: %.2f" (List.average gaussianValues)
printfn "Sample values:"
gaussianValues |> List.take 10 |> List.iter (printf "%.1f ")
printfn ""

let histogram = 
    gaussianValues
    |> List.map (int >> (/) <| 10 >> (*) 10)
    |> List.groupBy id
    |> List.map (fun (k, v) -> k, List.length v)
    |> List.sortBy fst

histogram |> List.iter (fun (range, count) -> 
    printfn "%2d-%2d: %s (%d)" range (range + 9) (String.replicate count "*") count)
```

The Box-Muller transform converts uniform random values into normally  
distributed ones. This is crucial for modeling natural phenomena that  
follow Gaussian distributions like heights, test scores, and measurement errors.

## Random cellular automaton

Cellular automata with random initial states model complex systems  
and emergent behaviors.  

```F#
open System

let generateRandomAutomaton width generations =
    let rnd = Random()
    
    // Random initial state
    let initialState = Array.init width (fun _ -> rnd.Next(2) = 1)
    
    // Rule 30 (elementary cellular automaton)
    let applyRule left center right =
        match (left, center, right) with
        | (true, true, true) -> false
        | (true, true, false) -> false
        | (true, false, true) -> false
        | (true, false, false) -> true
        | (false, true, true) -> true
        | (false, true, false) -> true
        | (false, false, true) -> true
        | (false, false, false) -> false
    
    let evolve state =
        Array.init width (fun i ->
            let left = if i = 0 then false else state.[i-1]
            let center = state.[i]
            let right = if i = width-1 then false else state.[i+1]
            applyRule left center right)
    
    let rec generate current generation acc =
        if generation = 0 then List.rev (current :: acc)
        else
            let next = evolve current
            generate next (generation - 1) (current :: acc)
    
    generate initialState generations []

let printAutomaton states =
    states |> List.iteri (fun gen state ->
        printf "%2d: " gen
        state |> Array.iter (fun cell -> printf "%s" (if cell then "█" else "·"))
        printfn "")

let automaton = generateRandomAutomaton 40 15
printfn "Random Cellular Automaton (Rule 30):"
printAutomaton automaton
```

The cellular automaton starts with a random configuration and evolves  
according to local rules. This demonstrates how simple random initial  
conditions can lead to complex patterns and behaviors.

## Random maze generation

Maze generation algorithms create random navigable structures for games  
and pathfinding demonstrations.  

```F#
open System

type Cell = { X: int; Y: int; Walls: bool * bool * bool * bool } // N, E, S, W

let generateRandomMaze width height =
    let rnd = Random()
    
    // Initialize grid with all walls
    let grid = Array2D.init height width (fun y x -> 
        { X = x; Y = y; Walls = (true, true, true, true) })
    
    let visited = Array2D.create height width false
    let stack = System.Collections.Generic.Stack<int * int>()
    
    // Start at random position
    let startX, startY = rnd.Next(width), rnd.Next(height)
    visited.[startY, startX] <- true
    stack.Push((startX, startY))
    
    let getNeighbors x y =
        [ (x, y-1, 0, 2); (x+1, y, 1, 3); (x, y+1, 2, 0); (x-1, y, 3, 1) ]
        |> List.filter (fun (nx, ny, _, _) -> 
            nx >= 0 && nx < width && ny >= 0 && ny < height && 
            not visited.[ny, nx])
    
    let removeWall x y dir =
        let (n, e, s, w) = grid.[y, x].Walls
        grid.[y, x] <- { grid.[y, x] with 
            Walls = match dir with
                    | 0 -> (false, e, s, w) // North
                    | 1 -> (n, false, s, w) // East  
                    | 2 -> (n, e, false, w) // South
                    | 3 -> (n, e, s, false) } // West
    
    while stack.Count > 0 do
        let (currentX, currentY) = stack.Peek()
        let neighbors = getNeighbors currentX currentY
        
        if List.isEmpty neighbors then
            stack.Pop() |> ignore
        else
            let (nextX, nextY, dir1, dir2) = neighbors.[rnd.Next(neighbors.Length)]
            visited.[nextY, nextX] <- true
            removeWall currentX currentY dir1
            removeWall nextX nextY dir2
            stack.Push((nextX, nextY))
    
    grid

let printMaze (maze: Cell[,]) =
    let height = Array2D.length1 maze
    let width = Array2D.length2 maze
    
    // Top border
    printf "+"
    for _ in 0..width-1 do printf "--+"
    printfn ""
    
    for y in 0..height-1 do
        // Vertical walls and cells
        printf "|"
        for x in 0..width-1 do
            let (_, e, _, _) = maze.[y, x].Walls
            printf "  %s" (if e then "|" else " ")
        printfn ""
        
        // Horizontal walls
        printf "+"
        for x in 0..width-1 do
            let (_, _, s, _) = maze.[y, x].Walls
            printf "%s+" (if s then "--" else "  ")
        printfn ""

let maze = generateRandomMaze 12 8
printfn "Random Maze (Depth-First Search):"
printMaze maze
```

This implements a randomized depth-first search maze generation  
algorithm. The approach creates mazes with exactly one path between  
any two points, ensuring solvability while maintaining randomness.
